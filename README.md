# PartyLauncher

Un launcher pour jouer à Wii Party et à ses mods (Mode Hiver, Mode Duo, Le sol est de lave…) sur PC, avec un Dolphin intégré.

## Télécharger

Prends l’installateur de ton système dans les [Releases](https://github.com/prstance/wp-launcher/releases/latest) :

- **Windows** : `PartyLauncher_x.y.z_x64-setup.exe`
- **macOS** (Apple Silicon) : `PartyLauncher_x.y.z_aarch64.dmg`
- **Linux** : `PartyLauncher_x.y.z_amd64.AppImage`

Ensuite, le launcher se met à jour tout seul depuis *Paramètres › À propos*.

## Ce qu’il te faut

Ton propre disque de **Wii Party**, version européenne (PAL, SUPP01), en ISO, WBFS ou RVZ. Le launcher et les mods ne contiennent aucun fichier du jeu : ils sont fabriqués à partir de ton disque au premier lancement.
